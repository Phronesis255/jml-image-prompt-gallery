# JML Image & Prompt Gallery

Public, read-only gallery authorized by its owner.

- 247 selected archive images with prompts, briefs or explicitly labeled reconstructions.
- 128 blog examples: four articles, eight visual styles, one cover and three supporting images per set.
- 12 standalone JML examples, source references, provenance and attribution.

Open `index.html` through a static web server. GitHub Pages serves the `main` branch root. No build, server credentials, tracking scripts, or password are required.

## Content and attribution

The gallery retains source credits and license notices where supplied. Public availability does not transfer ownership or grant a blanket license to third-party prompts, reference images or brands. AI-generated editorial examples are conceptual, not actual client photographs, evidence, metrics or outcomes. Prompt status labels distinguish recorded prompts, source templates, briefs, and reconstructions.

This public export omits private conversation links, local filesystem paths and attachment identifiers. The owner-private gallery remains separate.
